| 문서 | 역할 |

| [`ARCHITECTURE_PLAN_v3.md`](./ARCHITECTURE_PLAN_v3.md) | 목표 설계를 현재 코드에 적용하기 위한 구현 청사진 |

현재 프로젝트의 실제 구조와 동작은 [`../current/ARCHITECTURE.md`](../current/ARCHITECTURE.md)를 기준으로 확인한다.

## 주의사항

초기 버전의 문서일수록 최신 사항을 반영하지 않는 신뢰도가 낮은 문서이므로 문서 참조 시 항상 최신 버전을 참조할 것.
